# 正規文書本文へのメタ説明の禁止

## 対象

- 利用者やエージェントが参照して、そのまま従う正式な本文
- 例: `AGENTS.md`、`SKILL.md`、`*.rules`、ルール文書、ポリシー文書

## 禁止

- 「こういう指示でこうした」「これは間違っていた」「以前はこうだった」などの経緯、反省、会話ログを書く
- リファクタ理由、移行事情、議論の要約など、本文の読者がその場で従うために不要な説明を書く
- 「手順に含めない」「コピペ用」「適用: ...」のように、本文の使い方だけを説明するメタ段落を書く
- 変更履歴や検討過程を、正式な本文へ混ぜる

## 必須

- その場で従える規約、手順、事実だけを書く
- 背景や判断経緯が必要なら、コミットメッセージ、PR、調査メモ、ADR など本文以外へ分離する
- 1 回読めばそのまま使える、自己完結した本文にする
