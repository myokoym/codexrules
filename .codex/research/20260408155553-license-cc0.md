# CC0 ライセンス設定メモ

## 背景
- `rules` リポジトリに明示的なライセンスファイルが無かった。
- ユーザー意図は、このリポジトリを `CC0 1.0 Universal` で公開できるか確認し、問題なければ反映すること。
- 懸念点は、Codex / OpenAI の利用規約や生成物の権利関係に抵触しないかどうか。

## 確認した前提
- OpenAI の Terms of Use では、ユーザーが Output を保有できる旨が示されている。
- OpenAI の Service Terms では、Codex を含む code generation features の Output が第三者ライセンスの対象となる可能性がある旨が示されている。
- CC0 は、自分が保有する権利だけを放棄できる。保有していない第三者権利までは放棄できない。

## 今回の判断
- このリポジトリの現状ファイルは、個人作成の rules / README が中心で、第三者ライセンスをそのまま取り込んだ痕跡は見当たらないため、リポジトリ全体を `CC0-1.0` として扱う判断は妥当。
- ただし今後、外部ドキュメントや第三者コード片を追加する場合は、その部分を無条件に `CC0` 扱いしない。
- その注意点を README に追記して、運用で誤解しにくい状態にする。

## 反映内容
- ルートに `LICENSE` を追加し、`CC0 1.0 Universal` の標準文面を配置する。
- `README.md` に `CC0-1.0` の明示と、第三者由来コンテンツに関する注意書きを追加する。

- OpenAI Service Terms: https://openai.com/policies/service-terms/
